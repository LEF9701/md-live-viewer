# Changelog

## 0.3.0 — 2026-10-15

- New beginner-friendly Markdown Guide with pictures, side-by-side examples, copy/insert buttons, common mistakes, cheat sheet and a try-it box.
- Fix: quotes, inline code, keyboard keys, links and scrollbars now follow the preview's Light/Dark setting instead of the VS Code theme.

## 0.2.0 — 2026-10-15

- Activity bar icon with a sidebar dashboard: preview controls, theme, refresh mode, feature switches, document stats, outline and workspace Markdown files.
- Shortcut changed to Ctrl+Shift+Alt+V (was Ctrl+Alt+V, which clashed with other apps).

## 0.1.0 — 2026-10-15

- First release: live preview while typing, light/dark/auto theme, KaTeX math, Mermaid diagrams, syntax highlighting, scroll sync and double-click-to-source.
